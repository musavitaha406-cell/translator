# Translator

A simple desktop translator built with Python and tkinter. It translates any text into Persian (Farsi).

## Features
- Automatic source language detection
- Translates to Persian
- Press Enter or click the button to translate
- Simple tkinter GUI

## Setup
1. Install the dependency:
   pip install googletrans==4.0.0rc1
2. Run:
   python translator.py

## Note
An internet connection is required (uses Google Translate through the googletrans library).
